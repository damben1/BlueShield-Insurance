# BlueShield-Insurance
This is a responsive one-page insurance website.
Files included:
- `index.html` — complete responsive insurance company website

## Publish publicly
### Option 1: Netlify Drop (fastest)
1. Sign in to Netlify.
2. Go to the Netlify Drop page.
3. Drag and drop the folder that contains `index.html`.
4. Netlify will publish a live `.netlify.app` URL.

### Option 2: GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html` to the root of the repo.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
6. Save and wait a few minutes for the public URL.

## Customize before publishing
- Replace company name, phone, email, and address.
- Add your real insurance products and compliance disclosures.
- Connect the quote form to a backend, Power Automate, or CRM if you want real submissions.
